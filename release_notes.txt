# Nyxx v5.4.0

Release date: 2026-11-27

Mini-games, access control, bulk editing, backups and Web App hosting all get major upgrades in this release.

## 🎮 Mini-Games
- Game library expanded to **7 games** (classic arcade favorites such as Snake, Tetris, Minesweeper and a runner)
- New, wider game screen so playing on mobile and desktop is comfortable
- **Fixed:** the silent personal-best notice now sends a proper localized message (EN/FA)
- Per-game **Disallowed IDs** alongside Allowed IDs
- **"Edit current message"** option for game responses, with the same 3 triggers as elsewhere (inline button / reply button / typed command)
- Optional **custom label** for the "game is ready for username" message (`{{game}}`, `{{user}}`, `{{first_name}}`)
- Choose a game's **leaderboard as a button** when creating commands

## 🔐 Access Control
- New **Global Bot Access** setting: DM-only, group-only, channel-only, allowed IDs, disallowed IDs, premium-only, username-required, maintenance mode, and a custom deny message
- **Disallowed IDs** added to every media modal
- Account-based tab permissions: empty nav groups now disappear completely, and gates are more reliable

## ⚡ Productivity
- **Batch edit commands**: select many commands and change one setting (e.g. "Edit current message") for all of them at once

## 🌍 Language
- Choose which sections and messages use **Farsi** and which use **English**
- **Per-group / per-channel language** overrides the global language

## 🌐 Web App
- Default button can be set to a **Web App** button
- Pick one of your games or a **premade Nyxx template** as the main page
- Paste your own HTML, or build a **multi-page site with folders** from the dashboard (`/app/*`)

## 💾 Backup & Restore
- Backups include every setting and restore applies them
- AI tokens and other sensitive settings are **encrypted (AES-GCM, passphrase-based)** and decrypted on restore
- Optional inclusion of other sensitive settings in the encrypted payload

## 🎨 UI / UX
- Memory tab shows all D1 memory details and storage breakdown
- **Frosted Glass** is the default navigation style on fresh D1 installs
- Favicon on every page and game page, with proper meta titles and descriptions
- User names and display names are length- and overflow-protected so huge or stacked-glyph names can't break the layout

## 🛠 Fixes
- Many UI and logic fixes across commands, games, media and settings

Update from the dashboard's Update tab. Your bindings and secrets are preserved.
