## What's New in Nyxx v5.0.3

### 🔔 Browser Notifications
- **New Notifications tab** — opt-in browser alerts for new contact messages, delivered and routed to the Inbox by Nyxx's service worker.
- **Privacy and reliability controls** — browser-local enable/disable and preview preferences, a test notification, permission/status feedback, persisted message cursors to avoid repeat alerts, and safe handling of background polling errors.
- **Honest delivery limits** — polling runs about once a minute while the dashboard remains open; this is not web push and cannot notify while the dashboard is closed.

### 🛠️ Reliability
- **Bounded database queries** — invalid or negative contact, audit-log, and user-list pagination values now use safe limits instead of causing unbounded or invalid queries.
- **Service worker diagnostics** — registration failures are logged instead of being silently discarded.
- **Release integrity checks** — installer and in-dashboard updates verify the downloaded Worker against the release SHA-256 and version before deploying.
- **Proxy hardening** — malformed IPs fail closed, reserved address ranges are blocked, and incomplete DNS-over-HTTPS verification no longer permits hostname requests.

### ✨ New Featured Commands & Picker UI
- **10 New Featured Command Types** — Added **Media Library Search** (`/get`), **Native Poll** (`/poll`), **Live Proxy Tester** (`/checkproxy`), **Quick Group Moderation** (`/warn`, `/mute`, `/unmute`, `/kick`, `/ban`, `/unban`), **User Inspector** (`/whois` with admin quick-action buttons), **Anonymous Inbox** (`/anon`), **Chat-Side Broadcast** (`/announce` with preview/confirm), **Channel Post Formatter** (`/post`), **One-Shot AI Transform** (`/translate` / `/tldr`), and **Self-Destructing Temp Message** (`/temp`).
- **Categorized Featured Command Picker & Responsive Cards** — Replaced the crowded header buttons with a clean **New featured command** picker modal (grouped into *Messaging*, *Utilities & Media*, and *Moderation & Admin*), live search, category filter chips, and a responsive card grid for both desktop and mobile.
- **Featured Command ACL** — Added **Specific users** access mode plus **Allowed user IDs** and **Disallowed user IDs** inputs on every featured command.

### 🛠️ UI, Caching & Mobile Fixes
- **Service Worker & Browser Recovery Reliability** — Switched `/` navigation in `/sw.js` to network-first with offline fallback, added `CLEAR_ALL_CACHES` handling, moved Browser & Cache Tools to an early self-contained script so it works even before full page load, and fixed mobile button text overflow.
- **Settings, Update & Layout Polish** — Removed excess top spacing above sticky sub-tabbars, moved Cloudflare API token action buttons onto their own row below the input, fixed the Update hero button loading spinner overlap, and added mobile wrapping support to Global Anti-Flood's segmented control.

### 🗄️ Database
- Bumped schema to **v27** (adds `allowed_users`, `disallowed_users`, and `extra_config` on `featured_replies` via non-destructive migrations & auto-heal).
